Module 3 · Introduction to Coding

MICrONS one-day workshop

Author

Bethanny Danskin

Overview

In the first two modules you explored the MICrONS reconstruction through the browser. In this module you access the same data programmatically with Python and CAVEclient, the client for the Connectome Annotation Versioning Engine (CAVE). Querying the cloud lets you analyze thousands of cells and their connections without downloading the raw volume.

The notebook builds towards a cell-type-sorted connectivity matrix — a heatmap of who connects to whom across a cortical column.

Learning goals

  • Connect to CAVE and load a neuron’s morphology (skeleton) and its synapses.
  • Query cell-type tables and plot the spatial organization of cortical cell types.
  • Build a binary connectivity matrix and sort it by cell type into an interpretable heatmap.

Run the notebook

The notebook runs in Google Colab — nothing to install locally. Open it, then choose File → Save a copy in Drive to keep your own working copy.

ImportantOne-time account setup

Running code against CAVE needs a free CAVE token tied to a Google account, plus a one-time Terms-of-Service acceptance. Do this before the workshop — see Setup & FAQ. The token-setup notebook stores your token in Colab so you only enter it once.

What you’ll do

  1. Connect to CAVE and confirm your token works.
  2. Part 1 · Morphology — load one neuron as a skeleton, add its input and output synapses, and see which compartments (spine / shaft / soma) its synapses target.
  3. Part 2 · Connectivity — load all proofread-to-proofread connections in a cortical column and build a connectivity matrix (also called an edge list).
  4. Part 3 · Cell types — query the cell-type table and plot cell volume vs. cortical depth, colored by type.
  5. Part 4 · The payoff — sort the connectivity matrix by cell type into a heatmap that reveals circuit structure.
  6. Bonus — how weighting connections by synapse size vs. count changes the picture.
